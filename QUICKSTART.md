# 🚀 Quick Start Guide

## Getting Started in 3 Steps

### 1️⃣ Install & Run
```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) (or the port shown in terminal)

### 2️⃣ Setup Your Game

**Enter Player Names**
- Type player 1 name (plays as X)
- Type player 2 name (plays as O) - skip for AI mode

**Choose Game Mode**
- 🎮 **Classic** - Casual turn-based
- ⏱️ **Timed Blitz** - 30 seconds per move
- 🤖 **VS AI** - Play against computer

**Select AI Difficulty** (AI mode only)
- 🟢 Easy - Forgiving opponent
- 🟡 Medium - Balanced challenge
- 🔴 Hard - Expert player

### 3️⃣ Play!

Click "START GAME" and enjoy!

---

## 🎮 Controls

### During Game
- **Click cells** - Place your mark
- **☀/☾ button** - Toggle theme
- **⬅ button** - Return to menu
- **NEW ROUND** - Play again
- **RESET SCORE** - Clear scoreboard

### Music Player
- **▶/⏸** - Play/pause music
- **⏮/⏭** - Change track
- **🔊/🔇** - Mute/unmute
- **Slider** - Adjust volume

---

## 💡 Tips

### For Best Experience
1. **Enable audio** - Click play on music player
2. **Use headphones** - Hear all sound effects
3. **Try all modes** - Each offers unique challenge
4. **Watch combos** - Win multiple rounds in a row!
5. **Timed mode** - Move fast or lose your turn

### Strategy Tips
- Take the center first
- Control the corners
- Watch for opponent's two-in-a-row
- Think ahead in timed mode

### AI Difficulty Guide
- **Easy** - Learning the game? Start here
- **Medium** - Good challenge for most players
- **Hard** - Can you beat the optimal strategy?

## 🏆 Winning

**Victory Conditions:**
- Get 3 marks in a row (horizontal, vertical, or diagonal)
- In timed mode: Opponent runs out of time
- Draw: All 9 cells filled with no winner

**After Winning:**
- View your statistics
- Play next round
- Return to main menu

## 🐛 Troubleshooting

### No Sound?
- Click the music play button
- Check browser permissions
- Ensure volume isn't muted
- Try refreshing the page

### Game Not Loading?
```bash
# Clear node_modules and reinstall
rm -rf node_modules
npm install
npm run dev
```

### Port Already In Use?
Vite will automatically find an available port and show it in the terminal
